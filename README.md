# 童朝凯 · Chaokai Tong

**新能源 / 光伏 / 储能 IoT 软件开发工程师**  
Software engineer focused on photovoltaic and energy storage IoT platforms.

长期从事能源物联网平台的软件研发，主导设备协议与数据采集、储能业务适配、远程控制、固件升级、数据转发，以及开发者平台和备件购买平台的设计、开发与落地。

## 主导项目与工作方向

### 1. 设备接入与数据采集

主导设备接入和数据采集服务的设计开发，统一处理不同设备的数据格式，支持新设备与版本扩展，提供实时数据读取能力。

### 2. 储能与电池数据

主导储能与电池数据服务建设，整合设备、电池组和电芯等层级的信息，支持状态监测、告警及功率、电量等数据处理。

### 3. 能源管理

主导工商业与家庭储能场景的软件适配，支持按电价安排充放电、限制用电高峰、优化光伏自用、保留应急电量及控制并网功率等能源管理需求。

### 4. 设备远程控制

主导设备远程操作服务的设计开发，支持参数读取与设置、工作模式调整、电池充放电、充电桩控制和自动校时，完善操作结果追踪、失败重试与高并发处理。

### 5. 开发者平台

主导开发者平台设计、开发与上线，通过开放接口向第三方系统提供设备控制、数据读取和任务查询能力，完成系统对接与兼容适配。

### 6. 设备升级与自动化

主导设备软件升级服务建设，支持版本管理、自动筛选升级对象、批量更新、失败重试和进度查询，让升级过程可管理、可追踪。

### 7. 数据服务与平台稳定性

主导设备数据转发与平台稳定性建设，优化数据传递效率和异常恢复机制，降低延迟，完善运行监测、跨区域联调及生产问题定位。

### 8. 线上交易平台

主导备件线上购买平台设计、开发与上线，打通商品展示、购物车、下单、支付、订单同步、邮件通知和电子发票流程，完善交易异常处理。
